**📢 [Public Announcement Management System (PAMS)](https://github.com/krei-labs/public-announcement-management-system)**
A Computer Engineering thesis project — a Flask + SQLite web dashboard controlling a Raspberry Pi/Arduino campus PA system, with scheduled and emergency broadcasts, digital display rendering, TTS audio, and speaker-zone relay control.
- Project Leader & full-stack developer — architected and built the software, then integrated it with the Raspberry Pi/Arduino hardware
- **Stack:** Python · Flask · SQLite · Raspberry Pi · Arduino · PySerial · APScheduler

**📚 [Library Management System](https://github.com/krei-labs/library-management-system)**
A single-binary C++ console app that models a real library workflow — role-based accounts, borrowing/waitlists, undo history, and file persistence — combining OOP with hand-built data structures instead of the STL.
- Implemented every data structure (linked list, stack, queue) from scratch, plus salted/hashed authentication
- **Stack:** C++17 · hand-built linked list/stack/queue · file-based persistence
